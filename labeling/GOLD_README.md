# Эталонная разметка рамок — инструкция для разметчика

## Зачем

По этому эталону мы проверяем исполнителей в Яндекс Заданиях: экзамен для разметки рамок, обучение, экзамен и контрольные задания для ревью, а также примеры в инструкциях. Фото **не из датасета** — это 87 отдельных CC0-фото с iNaturalist (бабочки, моли, гусеницы, другие насекомые, цветы). Сами 400 фото датасета размечают исполнители, их мы не трогаем.

Эталон размечают **два человека независимо, одни и те же фото**. Где ответы совпали, берём среднюю рамку. Где разошлись, фото разбираем вместе или выкидываем. Поэтому не смотрите ответы друг друга.

## Как начать

1. Скачайте [`gold_tool.html`](gold_tool.html): на GitHub нажмите «Download raw file» или склонируйте репозиторий. Откройте файл в Chrome или Firefox двойным кликом. Нужен интернет: картинки грузятся с iNaturalist.
2. Размечайте **по порядку, начиная с №1**, минимум первые **50** фото, лучше все 87. Порядок фиксированный: так у обоих разметчиков будут одни и те же фото.
3. Прогресс сохраняется в браузере сам. Можно закрыть вкладку и вернуться — в **том же** браузере и не в режиме инкогнито.

## Правила рамок

Те же, что в задании и в инструкции исполнителям:

- Выделяем **каждую взрослую бабочку отдельной рамкой**, даже если бабочки перекрываются.
- Рамка **плотная** по видимым частям: крылья, тело, **усики и лапки**.
- Закрыта листом или обрезана краем фото — выделяем **только видимую часть**, скрытое не достраиваем.
- **Не выделяем как бабочку:** моль, гусениц, куколок, других насекомых, тени.
- Сомневаетесь, бабочка ли это, — не гадайте: нажмите **S** («спорно, не брать»), такое фото в эталон не пойдёт.

**Похожий объект.** Моль или другое насекомое обведите красной рамкой (клавиша **2**). Клавиши 1/2 переключают цвет *следующей* рамки; чтобы перекрасить уже нарисованную, сначала кликните по ней. В эталон бабочек она не попадает. Нужна, чтобы делать контрольные задания вида «лишняя рамка на моли» и картинку для инструкции «такое не выделяем».

## Управление

| Действие | Как |
|---|---|
| Нарисовать рамку | зажать мышь и тянуть |
| Рамка «бабочка» (зелёная) / «похожий объект» (красная) | **1** / **2** |
| Перекрасить уже нарисованную рамку | кликнуть по ней (появится синий пунктир), затем **1** или **2** |
| Выделить рамку / удалить / отменить последнюю | клик по рамке / **Del** / **Z** |
| Готово, бабочки выделены | **Enter** |
| Бабочек нет | **0** |
| Спорно, не брать | **S** |
| Картинка не грузится | кнопка «Не грузится» |
| Листать | **←** / **→** |

После Enter, 0 или S открывается следующее фото. В списке слева видно статус каждого фото и число рамок.

## Теги-примеры

Над фото есть галочки: *одна, несколько, перекрытие, похожее насекомое, без бабочек, обрезана краем, мелкая*. Если фото хорошо показывает такой случай, отметьте его. Из этих фото сделаем примеры для инструкции исполнителям. Нужно **хотя бы по одному фото на каждый тег**, а несколько вариантов — ещё лучше.

## Как сдать

1. Впишите своё имя латиницей в поле «ваше имя» справа вверху.
2. Нажмите **«Экспорт JSON»** — скачается `gold_<имя>.json`.
3. Отправьте файл Глебу или закоммитьте в `labeling/work/gold_<имя>.json`.

На 50 фото уходит примерно 25–30 минут.
