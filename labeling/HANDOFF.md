Этап bbox + review в Яндекс Заданиях **завершён**. Осталось собрать итоговую разметку всех 400 фото: решить 11 фото вручную, выборочно проверить принятые ответы и собрать `golden/`.

- Весь код и данные — ветка **`labeling-pipeline`**, папка `labeling/`. Подробности по коду и параметрам — [`labeling/README.md`](README.md) в этой ветке.
- Инструмент ручного разбора и инструкция к нему — ещё и в `main`: [`fix_tool.html`](fix_tool.html), [`FIX_README.md`](FIX_README.md).

## Что сделать

1. **Ручной разбор.** Открыть `fix_tool.html` → по [`FIX_README.md`](FIX_README.md):
   - № 1–11 — **обязательно** (без них нет разметки на все 400 фото);
   - № 12–77 — выборочная проверка принятых 2:1 (требование задания: «проверьте выборку итоговых ответов самостоятельно»).
   Экспорт → `labeling/work/fix_<имя>.json`. Можно делить на нескольких людей: каждый экспортирует свой файл, сборка берёт все `fix_*.json`.
2. **Сборка** (без токена, без интернета, Яндекс Задания не трогает):
   ```bash
   git checkout labeling-pipeline
   cd labeling
   pip install requests pillow          # если ещё нет
   python finalize.py build             # → ../golden/
   ```
   Проверить вывод: `golden: 400/400 фото`. Если пишет «нет итоговой разметки у N фото» — эти фото не разобраны в `fix_tool` (или помечены S).
3. **Отдать `golden/` на сравнение моделей** и закоммитить.

## Что получится в `golden/`

| Файл | Что внутри |
|---|---|
| `golden.jsonl` | итог на 400 фото в формате Контеста: `{"photo_id": int, "boxes": [{left, top, width, height}], "error": null}`, координаты в долях кадра |
| `golden_meta.tsv` | для каждого фото: группа, роль (positive/negative), источник разметки (`crowd_accept`, `crowd_accept_majority`, `team_fix`, `team_confirmed`; `_model` — если правили моделью), число попыток, голоса ревьюеров |
| `corrections.tsv` | журнал исправлений команды: что было, что стало, кто, пояснение |
| `raw_bbox_answers.jsonl` | все 444 ответа разметчиков: рамки, статус, решение |
| `raw_reviews.jsonl` | все 1332 вердикта ревьюеров |
| `pipeline_log.json` | переразметки и причины ручного разбора |

Для метрик по группам: `golden_meta.tsv` → колонки `group` и `role`.
