# Ручной разбор и выборочная проверка — инструкция

## Зачем

Исполнители Яндекс Заданий разметили все 400 фото датасета, каждый ответ проверили три ревьюера. Итог:

- **389 фото** — разметка одобрена ревью;
- **11 фото** — финального ответа нет: обе попытки разметки отклонены ревью (7) или разметчик отметил «не уверен» (4). **Их решает команда — без них нет golden set на все 400 фото.**
- **66 фото** из одобренных приняты со счётом 2:1 — это самые спорные ответы. Задание требует самим проверить выборку итоговой разметки: найденные ошибки пойдут в отчёт.

Ваше решение по каждому фото — окончательное и попадает в golden set, на котором сравниваются модели.

## Что делать

1. Скачайте [`fix_tool.html`](fix_tool.html) (на GitHub — «Download raw file») и откройте в Chrome или Firefox. Нужен интернет: картинки грузятся с iNaturalist.
2. Сверху над фото написано, что это:
   - **«РАЗБОР: …»** — № 1–11, **обязательно**. В тексте причина: `2 attempts rejected` — две разметки отклонены; `annotator doubt` — разметчик не был уверен.
   - **«ВЫБОРОЧНАЯ ПРОВЕРКА: …»** — № 12–77, проверка принятых. Желательно все; если нет времени — сначала сделайте 1–11 и пришлите, остальное потом.
3. На фото уже стоят рамки исполнителя (зелёные). Сравните с правилами ниже:
   - **всё верно** → **Enter**;
   - **есть ошибка** → поправьте: тяните рамку за край или угол, лишнюю — клик и **Del**, недостающую — нарисуйте мышью. Потом **Enter**;
   - **бабочек нет** (например, рамка на моли) → удалите рамки → **0**.
4. **Если что-то исправили — коротко напишите в поле «пояснение» что и почему**: «рамка на моли», «пропущена вторая бабочка», «обрезаны усики». Это журнал исправлений для отчёта.
5. На фото «РАЗБОР» **не нажимайте S** («спорно, не брать») — фото без ответа не попадёт в golden set. Если правда сложно, примите решение и напишите в пояснении «спорно».
6. Впишите имя латиницей → **«Экспорт JSON»** → файл `fix_<имя>.json` — пришлите Глебу или закоммитьте в `labeling/work/`.

Прогресс сохраняется в браузере (тот же браузер, не инкогнито).

## Правила рамок (как в задании)

- Каждая **взрослая бабочка** — отдельная рамка, даже если бабочки перекрываются.
- Рамка **плотно** по видимым частям: крылья, тело, **усики и лапки**.
- Закрыта листом или обрезана краем фото — **только видимая часть**.
- **Не выделяем:** моли (даже яркие дневные — у бабочки усики с булавой на конце, у моли нитевидные/перистые), гусеницы, куколки, другие насекомые, тени.

## Управление

| Действие | Как |
|---|---|
| Нарисовать рамку | зажать мышь и тянуть |
| Поправить размер | тянуть за край или угол рамки |
| Сдвинуть рамку | клик по ней, потом тянуть за середину |
| Удалить / отменить последнюю | клик по рамке + **Del** / **Z** |
| Готово (рамки верны) | **Enter** |
| Бабочек нет | **0** |
| Листать | **←** / **→** |

Красные рамки («похожий объект», клавиша 2) здесь не нужны.

Если модель использовалась для исправления — обязательно напишите в пояснении «model»: такие исправления не считаются независимой человеческой проверкой.

Время: 11 обязательных — ~10 минут, все 77 — ~40 минут.
